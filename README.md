# e-Gov Law Monitor

e-Govの法令データをもとに、法令の更新情報を収集・整理し、AI要約やキーワードによる更新通知を提供するサービスです。

## サービスサイト

[e-Gov Law Monitor](https://egovlm.oogushioffice.com/)

## 主な機能

- 法令更新情報の確認
- 法令改正や新規制定法令のAI要約
- キーワードによる法令ウォッチ
- 法令ウォッチのメール通知と通知ON／OFF設定

利用できる機能や利用上限はプランによって異なります。詳しくはサービスサイトをご覧ください。
