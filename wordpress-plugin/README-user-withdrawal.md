# 管理者用・退会前チェック

「法令ウォッチ → ユーザー管理」の各一般会員の「退会前チェック」から開きます。管理者本人、管理権限・投稿権限・内部API権限を持つ対象、subscriber以外のロールは対象外です。既存コードのAPIユーザー名`law_watch_api`も除外します。Application Passwordの登録がある場合はサービス用途の確認が必要として表示を停止します。認証情報そのものは表示しません。

GitHub Secretsに保存される投稿用・内部API用ユーザー名を、この画面から確認することはできません。既知の条件だけでサービスアカウントを完全に識別できるとは限らないため、管理者が別途確認してください。

画面はユーザー情報、保存プラン、Square契約、解約申請、旧申込、ウォッチ件数・通知設定、AI個人履歴件数・お試し回数、Standard同意記録、所有投稿タイプ別件数・コメント・リンク件数をSELECTで取得します。契約・解約・旧申込の詳細表示は最新100件、未完了解約と各件数は全件集計です。共有AIキャッシュは対象外です。

旧申込テーブルの不存在と読み取りエラーを区別します。その他の必要情報の取得に失敗した場合も、0件に置き換えません。プラン上限の適用など書込みを伴う既存取得関数は呼びません。

WordPressに保存した情報だけの確認であり、本人確認・Square Dashboardでの契約終了と課金停止の確認は別途必要です。「確認対象記録なし」でも退会可能とは判定しません。この段階には削除・承認解除・同意退避・監査書込み・Square API通信はありません。

投稿・メディアはWordPressの投稿タイプ設定、削除時の移管先、他プラグインによって扱いが異なります。本人のコメントはユーザー削除だけで全消去されるとは限りません。所有投稿を削除した場合、その投稿のコメントも影響します。UsersWP独自データやマルチサイトの削除挙動は別途調査が必要です。

ローカル検証：`php tests/user-withdrawal-check-test.php`。実DB・実WordPress・実ブラウザでの確認は別途行ってください。
